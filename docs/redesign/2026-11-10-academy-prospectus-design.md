# IT ACADEMY 최종 메인 구성안 구현 명세

## 기준 시안

이 문서는 이전 대화에서 제작한 「IT ACADEMY 성장의 시작」 메인 구성 이미지에 맞춰 실제 사이트를 구현하기 위한 명세입니다. 전반적인 에디토리얼 안내서 디자인으로 방향을 바꾼 이전 시도는 폐기합니다.

## 시각 아이덴티티

- 핵심 배경: 포레스트 그린과 짙은 녹색
- 본문 바탕: 웜 아이보리/웜 화이트
- 행동 강조: 따뜻한 오렌지
- 로고: 오렌지 A형 심볼 + IT ACADEMY + Learn · Build · Grow
- 폰트: Pretendard Variable, 한국어 가독성과 제목 계층을 우선
- 카드: 이미지가 먼저 보이고 짧은 정보가 이어지는 사진형/비주얼형 카드
- 버튼: 주 CTA는 오렌지, 보조 CTA는 투명·테두리 또는 그린 계열
- 내비게이션/푸터: 동일한 딥 그린을 공유

## 메인 화면 순서

1. 헤더 — A 로고, IT ACADEMY, Learn · Build · Grow, 교육과정·프로젝트·공지사항·상담 안내·기관 소개, 검색 바로가기, 오렌지 CTA
2. 히어로 — 좌측 큰 한글 제목 “IT로 만드는 당신의 새로운 시작”, 짧은 설명, 교육과정/프로젝트 버튼. 우측에는 개발 학습 사진과 코드·학습 진행 상태의 반투명 오버레이
3. 강점 스트립 — 커리큘럼 설계, 기술 중심 학습, 프로젝트 경험, 상담 안내 네 항목
4. 교육과정 — 설명 영역과 네 개의 사진형 카드. 카드에서 제목·핵심 설명·상세 이동을 제공
5. 프로젝트 — MOMO 영화 리뷰 커뮤니티 메인 배너와 IT ACADEMY 통합 플랫폼·AI 로또 분석기·날씨 생활 도우미의 세 개 보조 사례
6. 공지와 상담 — 좌측 실제 공지 목록/빈 상태, 우측 상담 안내 이미지 카드
7. 하단 CTA — 짙은 그린 사진형 밴드와 교육과정 진입 버튼
8. 푸터 — 동일한 A 로고와 교육과정·프로젝트·기관 안내 링크

## 하위 페이지 연결

- /courses: 동일한 웜 아이보리 배경, 그린 제목 영역, 사진형 과정 카드 네 개, 검색과 분야 필터
- /courses/:id: 딥 그린 과정 소개, 목표·커리큘럼·실습·산출물·운영 정보 영역
- /projects: 그린 프로젝트 소개와 사진형 갤러리, 키보드 접근 가능한 상세 모달
- /notices: 공지 분류별 의미 있는 태그 색, 제목·분류·날짜를 나눈 목록, 읽기 쉬운 상세 본문과 목록 복귀 링크
- /consultation: 그린 페이지 헤더, 상담 준비·절차·서버 연결 상태 안내. 정적 미리보기에서는 입력 폼을 숨기고 개인정보를 받지 않음
- /about: 그린 히어로와 교육 방향·학습 원칙·완료 기준

## 콘텐츠 무결성 원칙

구성 이미지의 시각 구조는 반영하되, 이미지에 보이는 전문 강사진·1:1 맞춤 로드맵·수강생 성공 사례·실제 공지 날짜처럼 검증되지 않은 운영 사실은 복사하지 않습니다. 실제 과정 운영 조건은 확정된 공지와 연결하고, 정적 사이트에는 샘플 공지를 실제 게시물처럼 넣지 않습니다.

## 완료 조건

- 모든 공개 페이지에서 로고·헤더·푸터·색·폰트·버튼·태그가 같은 브랜드 시스템을 공유
- 메인 8개 구역의 순서와 비중이 기준 이미지와 일치
- 교육과정 네 카드 및 프로젝트의 메인/보조 구조가 일치
- 360~1440px에서 가로 넘침이 없고 내비게이션·버튼·모달·폼에 키보드 포커스가 보임
- 실제 이미지 자연 너비, 링크, 페이지 이동, 공지 빈 상태와 상담 미리보기 동작을 Chromium에서 확인
